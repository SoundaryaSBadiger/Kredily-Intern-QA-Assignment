# BUG-002 — Malformed email receives mobile-number validation message

**Severity:** Medium  
**Priority:** P2  
**Status:** Observed / reproducible from supplied evidence

## Steps to Reproduce
1. Open the initial sign-in screen.
2. Enter 'peoplekredily1yopmail.com' without the @ separator.
3. Tap Continue.
4. Observe the validation message.

## Expected Result
The validation should state that the email format is invalid, or clearly explain that the field accepts either a valid email or a 10-digit mobile number.

## Actual Result
The field displays 'Enter a valid 10-digit mobile number' even though the user entered an email-like value. This is misleading and does not identify the email-format problem.

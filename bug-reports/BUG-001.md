# BUG-001 — Registered directory email is rejected by password login

**Severity:** High  
**Priority:** P1  
**Status:** Observed / reproducible from supplied evidence

## Steps to Reproduce
1. Open Directory and observe the listed employee email: peoplekredily1@yopmail.com.
2. Open the password sign-in screen.
3. Use the same email and submit the password.
4. Observe the error.

## Expected Result
A registered account should be recognized; if the password is wrong, the error should be an authentication/credential error rather than account-not-found.

## Actual Result
The password screen displays: 'No account found with this email or mobile number.' The Directory screenshot simultaneously lists the same email for the QA Assessment user.
